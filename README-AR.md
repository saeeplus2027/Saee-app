# تطبيق سعي بلس لأندرويد

هذا مشروع تطبيق Android بسيط يفتح موقع سعي بلس الحالي داخل WebView ويحافظ على تصميم الموقع كما هو:
https://saeeplus2027.github.io/Saee-plus2027/#home

## طريقة استخراج APK تلقائيًا من GitHub
1. أنشئ مستودع GitHub جديدًا باسم `SaeePlus-Android`.
2. ارفع محتويات هذا المجلد إلى المستودع (المجلدات والملفات الموجودة داخله، وليس ملف ZIP نفسه).
3. افتح تبويب **Actions** في المستودع وفعّل GitHub Actions إذا طلب منك ذلك.
4. شغّل سير العمل **Build Saee Plus APK** عبر **Run workflow**، أو ادفع الملفات إلى فرع `main` أو `master`.
5. بعد نجاح البناء، افتح تشغيل سير العمل وانزل إلى **Artifacts** ثم نزّل `Saee-Plus-APK.zip`.
6. فك الضغط على الهاتف وثبّت `app-debug.apk`. قد تحتاج للسماح بالتثبيت من هذا المصدر.

## ملاحظات
- هذا APK تجريبي غير موقّع للنشر في Google Play؛ مناسب للاختبار والتثبيت المباشر.
- التطبيق يحتاج اتصال إنترنت ويعرض الموقع المنشور، لذلك تغييرات الموقع تظهر عند تحديث الصفحة.
- الموقع المنشور حاليًا يوضح أن بعض الحسابات محفوظة محليًا على المتصفح. سلوك تسجيل الدخول وتخزينه داخل WebView يحتاج اختبارًا على الجهاز، ولا يعني تحويل الموقع وحده أن الحسابات أصبحت مركزية.
